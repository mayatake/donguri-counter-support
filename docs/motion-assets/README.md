# スクロール演出用キャラクター素材

すべて個別に配置・移動できる透過PNGです。公開中のLP本編ではなく、`landing-motion.html` のプロトタイプだけが参照します。

| ファイル | 役割 |
| --- | --- |
| `master-acorn.png` | スクロール全体を歩く主役 |
| `bear.png` | 仲間の章で現れるクマ |
| `squirrel.png` | 木の近くから現れるリス |
| `tanuki.png` | 返却の場面に現れるタヌキ |
| `bird.png` | 樹冠を横切る鳥 |
| `hedgehog.png` | 地面から遅れて現れる小動物 |

## 共通の画像生成指示（要約）

- 秋色の絵本調2Dイラスト。丸みのある形、細いこげ茶色の輪郭、控えめな紙の質感と柔らかな陰影。
- 各キャラクターは単体・全身・中央配置。文字、背景、地面、影、追加の小物は入れず、外側は透明。
- 表情は半目のジト目と小さな無表情の口に統一。追加した鳥・ハリネズミはページ上のまぶたオーバーレイでジト目を補強。
- マスターどんぐり、クマ、リス、タヌキは既存アプリ内イラストを参照。鳥とハリネズミは同じ配色・描線の言語に合わせた新しい候補。

## 試作ページ

`../landing-motion.html` は ScrollCraft の pin / cue を使った6章のスクロール演出デモです。キャラクター画像自体はこのディレクトリに分離し、季節差し替えや配置の調整をしやすくしています。
