# どんぐりカウンター｜ランディングページ絵コンテ

## ねらい

「どんぐりを拾う・数える」体験から、「見つけた場所へ戻し、自然や公園を大切にする」気持ちへつなぐ。アプリの機能を並べるより、マスターどんぐりと森の仲間たちが歩く短い物語として見せる。

## 6章構成

| 章 | 画面と動き | 登場キャラクター | 伝えること |
|---|---|---|---|
| 1. 見つける | 秋の公園を背景にマスターどんぐり。スクロールで落ち葉が流れ、遠くにクマの気配。 | マスターどんぐり、クマ（背景） | いつもの公園で、小さな発見をする。 |
| 2. 数える | 撮影画面のイラストと短い3ステップ。数を確かめる動きに合わせて、どんぐりがマスターのそばへ集まる。 | マスターどんぐり | 写真を撮り、数を確認し、見つけた記録にする。 |
| 3. 仲間に会う | 仲間たちが一場面にまとまって登場。スクロールで視線が順に集まる。 | クマ、リス、タヌキ | 森にはそれぞれの暮らしがある。初期キャラクターを紹介する。 |
| 4. 森を見る | 落ち葉や木の根元を見渡す静かな余白の章。動物は背景に控えめに置く。 | リス（小さく） | 数えることをきっかけに、場所や季節にも目を向ける。 |
| 5. 元の場所へ戻す | マスターどんぐりが地面にどんぐりを戻す。スクロールで手元から木の根元へ視線を移す。 | マスターどんぐり、タヌキ（遠景）、クマ（見守る） | どんぐりは森の仲間の食べもの。見つけた場所の近くへ戻そう。 |
| 6. また森で | 夕方の森に仲間が小さく集まり、最後は余韻を残してCTAへ。 | 全員（小さく） | 公園を大切にしながら、また見つけに行こう。 |

## 絵の密度

- 大きく見せる主役は各章1体まで。
- 仲間紹介の章だけ複数キャラクターを同時に見せる。
- タヌキは返却の章で遠景に置き、初期キャラクターとして気づける程度に登場させる。
- 季節画像を入れ替えやすいよう、季節の景色とキャラクター素材を章ごとに分ける。
- 既存アプリの秋の森の画像を初回ビジュアルに使い、季節切り替え時は画像・背景色・短い紹介文をまとめて更新する。

## コピーの軸

> 見つけたら、数えてみよう。  
> 数えたあとは、森へ返そう。

禁止や注意で締めず、「また会おうね」という気持ちでページを終える。
